# Kịch bản demo/bảo vệ 10–15 phút

1. TV1 (2 phút): bài toán, ERD, kiến trúc và phân quyền.
2. TV2 (3 phút): hội viên → đăng ký gói → hóa đơn → thanh toán; cho xem rollback lỗi.
3. TV3 (3 phút): lịch lớp → hai booking tranh chỗ cuối → check-in.
4. TV4 (2 phút): dashboard, tìm kiếm, báo cáo dùng View/SP/Function.
5. TV1 (1 phút): execution plan index, GRANT/DENY và kết luận.

Trước buổi bảo vệ phải clone mới, chạy database sạch, cấu hình User Secrets, chạy app và diễn tập trên đúng máy trình chiếu. Chuẩn bị dữ liệu seed cố định và phương án khôi phục bằng script, nhưng không thay demo trực tiếp bằng ảnh.
