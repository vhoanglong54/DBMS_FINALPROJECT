| Phần | Trang dự kiến | Owner chính |
|---|---:|---|
| Bìa, mục lục, danh mục hình/bảng | không tính | TV1 |
| Chương 1 — Tổng quan đề tài | 6–8 | TV1 |
| Chương 2 — Phân tích & thiết kế CSDL | 14–18 | TV1 tổng hợp; TV2/TV3 module |
| Chương 3 — Cài đặt SQL Server | 14–20 | TV2/TV3; TV1 security/core |
| Chương 4 — Transaction & bảo mật | 8–12 | TV1 + TV2/TV3 |
| Chương 5 — Xây dựng ứng dụng | 12–18 | TV4 + tất cả module owner |

| Phụ lục phân công/source | không tính | TV1 |

Mỗi ảnh phải có số, chú thích và được nhắc trong nội dung. Mỗi đối tượng SQL phải giải thích nghiệp vụ, không chỉ dán code. Bằng chứng index gồm query, execution plan và `STATISTICS IO/TIME`; concurrency gồm hai session và kết quả cuối.
